# RIO JOIAS — BarraShopping

Vitrine institucional estática e responsiva para a RIO JOIAS do BarraShopping.

## Conteúdo confirmado

- Perfil de referência: [@riojoiasbarrashopping](https://www.instagram.com/riojoiasbarrashopping/)
- Ouro 18k, prata e pedras preciosas
- Joias personalizadas e consertos
- BarraShopping, Nível Américas, Loja 216A
- Telefone: (21) 2431-9211
- Endereço: Avenida das Américas, 4666 — Barra da Tijuca, Rio de Janeiro — RJ

Os dados de localização e telefone foram conferidos na página oficial da loja no BarraShopping.

## Desenvolvimento local

O projeto não requer build. Sirva a pasta com um servidor HTTP local:

```powershell
python -m http.server 4173
```

Depois, abra `http://localhost:4173`.
